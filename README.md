# PLP Python Week 4 Assignment

This repository contains Python scripts demonstrating basic function creation, default parameter usage, and module imports.

## Files
- `toolbox.py`: Contains utility functions (`add_numbers`, `is_even`, and `greet`).
- `welcome.py`: Main script that imports functions from `toolbox.py` and prints the results.

## Reflection
The hardest function to write was `greet` because setting up the default parameter syntax (`greeting="Hello"`) required making sure the positional argument (`name`) came first. Once the parameter order was correct, using formatted strings (`f-strings`) made returning the custom message straightforward.
